# ProfundCentaur

ProfundCentaur integrates streaming-data processing with predictive-modeling capabilities, leveraging artificial-intelligence to optimize and schedule high-throughput data pipelines.

ProfundCentaur is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ProfundCentaur.git`
2. `cd ProfundCentaur`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
